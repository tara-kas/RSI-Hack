# Stating the answer

A model judge reads your reply, extracts **one** final answer, and compares it against a
reference. Solve the question however you like — these are only the things that lose a point
you have already earned.

End your reply with the answer on its own line, and nothing after it.

## The answer must be extractable and unique

- If no final answer can be extracted, it is marked wrong. Never trail off into discussion.
- Offering two candidates, or hedging with "approximately", "roughly" or "either X or Y",
  reads as ambiguous and is marked wrong. Commit to one.
- Do not restate options you ruled out near the end, where they can be mistaken for the
  answer.
- A wrong answer and no answer score the same, so always give your best one. There is never
  a reason to withhold.

## Give the answer in the form the question implies

Most questions do not state a format. Infer it from what is asked.

- **Asked to choose** — give the choice itself and nothing else. If the options are lettered,
  the letter alone is usually what is wanted.
- **Asked for a quantity** — a bare number, with units only if the question uses units.
  Match any stated precision or number of decimals.
- **Asked to name or identify** — the name alone, in the question's own terminology.
- **Asked for an expression** — the expression, in the notation the question uses.
- **Asked for several things** — answer every part, in the order asked, separated clearly.
  Roughly one answer in six has more than one component, and a partial answer scores nothing.

## Keep exact things exact

- An exact result stays exact: a fraction stays a fraction, a symbolic expression stays
  symbolic, a root or logarithm stays unevaluated, unless a decimal is requested. Evaluating
  `a/b` to a rounded decimal can turn a correct answer into a wrong one.
- Conversely, if a decimal is requested, give a decimal to the precision asked.
- Keep scientific notation when magnitudes are extreme, and keep the exponent's sign.
- Where the question writes symbols in a particular script or notation, mirror it rather
  than transliterating.

## Domain notes

- **Chemistry** — give formulas and species in standard notation with correct subscripts,
  charges and state symbols where they matter. Keep significant figures consistent with the
  data given.
- **Computer science** — asymptotic answers keep their notation and variable; a complexity
  answer is the bound itself, not a sentence about it. Outputs of code are given exactly as
  the program would print them, including case and spacing.
- **Engineering and physics** — carry units through and state them in the answer when the
  quantity is dimensional. Match the unit system the question uses rather than converting.

## If the question includes an image

Some questions reference a figure in the workspace. If you cannot read it, answer from the
text and your domain knowledge rather than refusing, and still give a single definite answer.
